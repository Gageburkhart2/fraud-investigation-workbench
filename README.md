# Fraud Investigation Workbench

A local-first fraud analysis project: detect suspicious card transactions, then generate evidence-based investigation summaries with a locally run LLM. No external AI APIs.

## Data

All data is synthetic and generated by `src/generate_transactions.py`. No real customer or bank data is used.

## Approach

1. Generate synthetic transactions with injected fraud patterns
2. Detect suspicious activity with rules and a statistical model
3. Summarize each case with a local LLM, citing transaction evidence
4. Evaluate detection quality, summary accuracy, and speed
